# Things

Everything in Punk is a **thing**. Space separates things, `[ ]` groups
them.

```punk
Paul
```
**`Paul`**

```punk
[Paul is 42]
```
**`[Paul is 42]`**

Numbers, text and logical values are all just words (THING-3). There are
no reserved words, so `TRUE` and `FALSE` are ordinary words (LEX-7).

```punk
[42 hello TRUE]
```
**`[42 hello TRUE]`**
